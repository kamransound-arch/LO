# UO

Mobilvennlig lagerregister for Bærum Kulturhus og Sandvika Teater.

## Publisering på GitHub Pages

1. Opprett et **nytt repository** på GitHub, for eksempel `UO`.
2. Pakk ut ZIP-filen og last opp **alle filene i rotmappen** i repositoryet (ikke selve ZIP-filen).
3. Åpne **Settings → Pages**.
4. Velg **Deploy from a branch**, branch `main`, mappe `/ (root)`, og trykk **Save**.
5. Når Pages er aktivert, åpne adressen som GitHub viser, vanligvis `https://BRUKERNAVN.github.io/UO/`.
6. Åpne siden i Safari på iPhone, trykk **Del → Legg til på Hjem-skjermen**.

## Viktig

- Appen bruker data fra **april 2026**.
- All redigering og alle flyttinger lagres **lokalt i nettleseren på den aktuelle enheten**.
- GitHub Pages gir **ikke** felles database, innlogging eller synkronisering.
- Ta regelmessig JSON-sikkerhetskopi fra appen. Nettleserdata kan slettes.
- GitHub Pages-nettstedet kan være offentlig. Ikke legg personopplysninger eller hemmeligheter i filene.
- Offline-funksjonen virker etter at siden er åpnet fra HTTPS og filene er bufret.
- Ukjent romplassering må registreres manuelt; ikke anta fordeling.
